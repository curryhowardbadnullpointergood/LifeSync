# LifeSync


**LifeSync** is a calendar and task management app designed to help users take control of their time through a series of complex algorithms that maximise time spent on activites you want while balancing work and health. 

## Features

- **Custom Calendar Views** – Navigate between week, month, and year views.
- **Task Manager with Priority & Points** – Add tasks with descriptions, estimated time, and color-coded priority levels (High, Medium, Low).
- **Searchable & Expandable Tasks** – View task details, mark them as complete, edit, or filter by title.
- **Time Estimation vs. Actual Tracking** – Compare estimated vs. actual time spent for self-analysis.
- **Gamification with Points** – Earn points for completing tasks and set reward milestones.
- **Nested Categories** – Organize tasks hierarchically (e.g. “Reading” → “Catcher in the Rye”).
- **Planned: Recurring Tasks** – Morning routines, weekly habits, etc.


## Tech Stack

- **Frontend:** HTML, SCSS (dark theme), JavaScript
- **Backend:** Golang, wails
